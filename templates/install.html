Pasang LYZNART di Perangkatmu

LYZNART bisa dipasang seperti aplikasi: ikonnya muncul di layar utama, terbuka layar penuh, dan halaman yang pernah dibuka tetap bisa diakses saat sinyal lemah. Instalasi tidak wajib, karena LYZNART tetap bisa dipakai langsung lewat browser.

{{ mascot(120, "bob") }}

{{ icon('robot') }} Android (Chrome)

  1. Buka LYZNART di Google Chrome.
  2. Tekan tombol {{ icon('install') }} Install LYZNART di atas, atau ketuk menu ⋮ di kanan atas.
  3. Pilih “Instal aplikasi” / “Tambahkan ke layar utama”.
  4. Tekan Instal. Ikon LYZNART muncul di layar utama HP.

{{ icon('pointer') }} Laptop/PC (Chrome/Edge)

  1. Buka LYZNART di Chrome atau Microsoft Edge.
  2. Klik tombol {{ icon('install') }} Install LYZNART, atau ikon ⊕ / monitor dengan panah di ujung kanan kolom alamat.
  3. Klik Instal.
  4. LYZNART terbuka di jendela sendiri dan bisa dicari di menu Start/Launchpad.

{{ icon('install') }} iPhone/iPad (Safari)

  1. Buka LYZNART di Safari.
  2. Ketuk tombol Bagikan (kotak dengan panah ke atas).
  3. Gulir lalu pilih “Tambah ke Layar Utama”.
  4. Ketuk Tambah.

{{ icon('question') }} Pertanyaan Umum

Apakah wajib menginstal?

Tidak. Semua fitur bisa dipakai langsung di browser. Instalasi hanya membuat akses lebih cepat.

Tombol Install tidak muncul?

Tombol hanya muncul di browser yang mendukung (Chrome, Edge, Samsung Internet) dan saat situs dibuka lewat HTTPS. Jika LYZNART sudah terpasang, tombol juga tidak muncul. Gunakan menu browser seperti pada petunjuk di atas.

Apakah progres tersimpan di aplikasi?

Progres tersimpan di server LYZNART pada akunmu, jadi tetap aman baik dibuka lewat browser maupun aplikasi, bahkan di perangkat lain.

Bagaimana cara menghapus aplikasinya?

Android: tekan lama ikon, pilih Uninstall. Laptop: buka LYZNART, klik menu ⋮ pada jendela aplikasi, lalu pilih “Uninstall”.
